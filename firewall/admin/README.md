# 관리자 접근통제 — 정서윤

`setup.sh`가 관리자 계정, SSH 인증 및 관리자 IP 허용 규칙을 설정합니다. 실행 전에 로컬 `.env`에 비어 있지 않은 `ADMIN_PASSWORD`를 지정하세요.

1. `$ADMIN_USERNAME` 계정을 생성합니다. 기본 제안은 `labadmin`입니다.
2. `$ADMIN_PASSWORD`가 비어 있으면 오류로 종료합니다. 비밀번호는 각자의 `.env`로 입력하고 소스·로그에 남기지 않습니다.
3. ID/PW 인증과 root 직접 로그인 제한을 설정합니다.
4. `TEAM_INPUT`에서 `$ADMIN_IP`만 TCP 22에 접근하도록 허용합니다. 나머지는 INPUT 기본 DROP에 맡깁니다.
5. `ssh-keygen -A`로 실행 시 호스트키를 생성하고 `/run/sshd`를 준비합니다. 키를 GitHub에 넣지 않습니다.
6. SSH 서버를 시작한 뒤 반환합니다. 공통 스크립트가 컨테이너를 유지하므로 `sshd -D`로 반환을 막지 않습니다.

관리자 정상 로그인·잘못된 비밀번호·비인가 IP 차단과 기존 HTTP 동작 유지를 확인합니다. 실제 규칙 변경 권한까지 과제에서 요구하는지도 확인합니다. 로그인과 규칙 변경 권한은 별개입니다.

전체 iptables 초기화나 FORWARD·NAT 수정은 하지 않습니다. 컨테이너 재생성으로 SSH 호스트키가 바뀌면 대상 IP의 known_hosts 항목만 확인 후 제거하고, 호스트키 검증을 전역으로 끄지 않습니다.
