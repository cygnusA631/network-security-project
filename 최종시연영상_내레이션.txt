도커 기반 네트워크 보안 프로젝트 시연입니다. 관리자와 일반 사용자, 방화벽, 웹서버까지 네 컨테이너가 실행 중이며, 웹서버의 정상 상태를 확인합니다.

관리자와 일반 클라이언트가 방화벽 외부 주소로 웹 접속을 시도합니다. 두 요청 모두 HTTP 200 응답과 웹서버 접속 성공 메시지를 받습니다. 허용한 웹 서비스가 정상 동작합니다.

브라우저에서 방화벽을 거쳐 접속한 웹화면입니다. 로컬 8080포트로 요청하면 웹서버 접속 성공 화면이 표시됩니다. 개발자 도구에서 요청 주소와 응답도 확인합니다.

다음은 관리자 접속입니다. 올바른 아이디와 비밀번호로 인증하면 원격 사용자 이름인 labadmin이 출력됩니다. 잘못된 비밀번호는 permission denied 응답으로 거부됩니다. 일반 클라이언트의 ssh 연결은 인증 전에 차단되며, input drop counter가 증가합니다.

방화벽 자체를 향하는 비허용 트래픽을 검사합니다. TCP 443번 포트 연결은 실패하고, UDP 9999번 패킷도 drop counter를 증가시킵니다. 접속 결과와 카운터를 함께 확인해 실제 차단을 검증합니다.

이번에는 정적 경로를 추가한 상태에서 비교합니다. 방화벽 외부 주소의 웹 접속은 성공하지만, 내부 웹서버 주소를 직접 지정한 연결은 차단됩니다. 80 번과 443 번 TCP, UDP 패킷의 forward drop 증가를 확인하고, 테스트용 경로를 제거합니다.

마지막은 재생성 후 재검사입니다. 먼저 19개 항목을 검사하고, 컨테이너와 네트워크를 종료한 뒤 같은 이미지로 다시 생성합니다. 화면은 빌드와 대기 구간을 단축했습니다. 재생성 후에도 웹 접속과 관리자 인증, 비허용 트래픽 차단과 우회 방지를 동일하게 검사합니다. 설정을 다시 적용해도 같은 결과가 나오는지 확인합니다.

최종 결과는 19개 검사를 재생성 전후 두 번 수행해 총 38회 통과, 실패 0회입니다. 이상으로 시연을 마치겠습니다.
